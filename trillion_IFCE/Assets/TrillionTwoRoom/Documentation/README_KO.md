# 투룸 모델 사용 안내

도면의 면적 수치를 ㎡로 해석하여 만든 추정 치수 모델입니다. 실제 건축 치수 또는 공인 면적이 아닙니다. 표시된 방 면적을 우선 맞췄으며 다용도실·현관·화장실·발코니는 도면 비례로 추정했습니다.

- 작은 침실: 2.96 × 3.00m = 8.88㎡
- 큰 침실: 4.30 × 3.00m = 12.90㎡
- 거실: 4.30 × 3.00m = 12.90㎡
- 주방·식당: 4.20 × 3.20m = 13.44㎡
- 화장실: 1.24 × 1.90m = 2.36㎡
- 현관: 1.40 × 1.60m = 2.24㎡
- 다용도실: 1.40 × 1.80m = 2.52㎡
- 복도: 1.24 × 1.30m = 1.61㎡
- 발코니: 1.30 × 6.40m = 8.32㎡

각 공간에 01_Finishes/벽·바닥·천장, 02_Fixed_Trim, 03_Furniture, 06_Doors_and_Windows, 07_Lighting, 08_Blinds를 나눴습니다. 옵션 교체용 컨피규레이터는 포함하지 않았습니다.

씬: Assets/TrillionTwoRoom/Scenes/TwoRoomApartment.unity
모델 프리팹: Assets/TrillionTwoRoom/Prefabs/TwoRoomApartment.prefab

Play 후 WASD 이동, 마우스 시선, E 문 열기·닫기, Esc 커서 해제. 카메라는 눈높이 1.5m, 시야각 65도입니다. 외부 바닥은 40 × 40m입니다.

원룸 씬은 별도 보존되어 있습니다. 모델 프리팹의 문의 player 참조는 배치한 플레이어를 지정해야 합니다. 제공 씬에는 지정되어 있습니다.
