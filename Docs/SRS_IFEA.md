# 1. 서론

## 1.1 목적

본 문서는 Interior Finish Cost & Energy Analysis 프로젝트의 소프트웨어 요구사항을 정의하는 것을 목적으로 한다.

본 시스템은 사용자가 사전 정의된 Room Type을 선택한 후 3D 공간에서 벽, 바닥, 천장, 조명, 블라인드, 커튼 등의 실내 마감 및 설비 항목을 선택, 변경, 제거할 수 있도록 한다.

시스템은 사용자의 선택 내용을 기반으로 견적 금액을 실시간 산출하고 적용된 자재의 열성능을 반영하여 예상 연간 에너지 사용량, 에너지 비용, 기준안 대비 절감액, 투자 회수기간을 계산한다.

본 문서는 프로젝트 기획, UI 설계, Unity 개발, 데이터 구성, 테스트 과정에서 기준 문서로 사용한다.

팀원은 기능 구현 범위, 입력 조건, 처리 조건, 출력 조건, 성능 기준, 검증 방법을 본 문서에 따라 확인한다.

## 1.5 작성 규칙

### 요구사항 표현과 우선순위

모든 요구사항은 한 문장에 하나의 내용만 담고, 아래 표현과 우선순위를 사용한다.

| 표현 | 의미 | 우선순위 |
|---|---|---|
| ~해야 한다 | 반드시 구현하는 필수 요구사항 | Must |
| ~하는 것이 좋다 | 구현이 바람직하나 일정에 따라 미룰 수 있는 요구사항 | Should |
| ~할 수 있다 | 여유가 있을 때 구현하는 선택 요구사항 | Could |

### 요구사항 ID 체계

| 구분 | ID 형식 | 예 |
|---|---|---|
| 기능 요구사항 | FR-번호 | FR-01 |
| 비기능 요구사항 | NFR-번호 | NFR-01 |
| 화면(사용자 인터페이스) | UI-번호 | UI-01 |
| 테스트 케이스 | TC-번호 | TC-01 |

### 모호한 표현 금지

"대략", "일반적으로", "적절히", "빠르게", "등"과 같은 표현, "/"로 묶은 표현, 이중 부정문을 쓰지 않는다. 측정 가능한 숫자와 조건으로 기술한다.

| 수정 전 | 수정 후 |
|---|---|
| 시스템은 빠르게 응답해야 한다. | 시스템은 요청의 95% 이상을 2초 이내에 응답해야 한다. |
| 사용자 친화적인 화면이어야 한다. | 사용자는 3번 이내의 클릭으로 주요 기능에 접근할 수 있어야 한다. |

## 1.6 문서 구성

본 문서는 프로젝트의 전체 요구사항을 다음과 같이 구성한다.

2장에서는 제품의 목적, 주요 기능, 사용자, 제약 조건을 설명한다.

3장에서는 Room 선택, 마감재 변경, 견적 계산, 에너지 분석과 관련된 기능 요구사항을 정의한다.

4장에서는 사용자 인터페이스와 하드웨어 인터페이스를 정의한다.

5장에서는 성능, 사용성, 호환성과 같은 비기능 요구사항을 정의한다.

6장에서는 Room 정보, 마감재 정보, 가격 정보, 열성능 데이터에 대한 요구사항을 정의한다.

7장에서는 각 요구사항의 검증 방법과 테스트 기준을 정의한다.

8장과 9장에서는 요구사항 변경 절차와 문서 검토 및 승인 절차를 정의한다.

# 2. 제품 개요

본 시스템은 사용자가 사전에 정의된 Room Type을 선택하고, 3D 공간에서 벽, 바닥, 천장, 조명, 블라인드, 커튼을 선택하여 공간 구성을 변경할 수 있는 프로그램이다.

선택한 항목은 Room에 즉시 반영되며, 제품 단가와 적용 면적 또는 수량을 기준으로 예상 견적을 계산한다.

또한 선택한 마감재의 열성능 정보를 이용하여 예상 연간 에너지 사용량과 에너지 비용을 산출하고, 기준안과 비교하여 예상 절감액과 투자 회수기간을 제공한다.

본 시스템은 사용자가 실내 마감 선택에 따른 초기 비용과 장기 에너지 비용의 변화를 함께 확인할 수 있도록 지원하는 것을 목적으로 한다.

---

## 2.1 제품 관점

본 시스템은 Unity 기반의 독립 실행형 3D 프로그램으로 구성한다.

사용자는 사전에 제작된 Room Type을 선택한 후 해당 공간을 1인칭 시점으로 이동하며 실내 마감 항목을 변경할 수 있다.

시스템은 사용자의 선택 정보를 내부 제품 데이터와 연결하여 Room의 시각적 상태를 변경하고 견적 금액, 열성능, 예상 연간 에너지 사용량, 에너지 비용, 투자 회수기간을 계산한다.

본 시스템은 외부 서버나 별도 하드웨어 연동 없이 PC 환경에서 단독으로 실행하는 것을 기본으로 한다.

### 시스템 구성 흐름

사용자  
→ Room Type 선택  
→ 3D Room 진입  
→ 벽, 바닥, 천장, 조명, 블라인드, 커튼 선택  
→ 견적 계산  
→ 열성능 계산  
→ 연간 에너지 사용량 및 비용 계산  
→ 투자 회수기간 확인

### 유사 제품 비교

| 제품 | 공통점 | 차이점 |
|---|---|---|
| 3D 인테리어 Configurator | 공간 내 마감재와 제품을 선택하고 시각적으로 변경할 수 있다. | 본 시스템은 마감 변경 결과와 함께 견적과 에너지 성능을 계산한다. |
| 건물 에너지 해석 프로그램 | 건물의 열성능과 에너지 사용량을 분석할 수 있다. | 본 시스템은 전문 설계용 해석보다 사용자의 마감재 선택에 따른 비용과 에너지 변화 비교에 초점을 둔다. |

## 2.2 제품 기능

본 시스템은 사용자가 Room Type을 선택한 후 3D 공간에서 실내 마감 항목을 변경하고, 그 결과에 따른 견적과 에너지 성능을 확인할 수 있도록 한다.

주요 기능은 다음과 같다.

- 사전 정의된 Room Type 선택
- 1인칭 시점의 Room 내부 이동
- 벽 마감재 선택 및 변경
- 바닥 마감재 선택 및 변경
- 천장 마감재 선택 및 변경
- 조명 선택 및 변경
- 블라인드 선택, 변경 및 제거
- 커튼 선택, 변경 및 제거
- 선택 항목의 실시간 견적 계산
- 마감재 열성능 계산
- 예상 연간 에너지 사용량 산출
- 예상 연간 에너지 비용 산출
- 기준안 대비 예상 절감액 계산
- 추가 투자비에 대한 투자 회수기간 계산
- 선택 항목과 분석 결과 초기화

| 기술 | Unity 기반으로 개발하며 Windows PC 환경에서 실행한다. |
| 분석 정확도 | 연간 에너지 사용량과 에너지 비용은 단순화된 계산식과 입력 조건을 기반으로 한 추정값으로 제공한다. |
| 범위 | 건물 전체 설계, 구조 설계, 가구 배치, 정밀 열유체 해석, 건축 인허가용 에너지 해석은 포함하지 않는다. |

## 2.5 가정 및 의존성

- 사용자는 Windows PC에서 프로그램을 실행한다.
- 사용자는 사전에 정의된 Room Type 중 하나를 선택하여 사용한다.
- 각 Room Type의 바닥 면적, 벽 면적, 천장 면적, 창 면적은 사전에 입력된 값을 사용한다.
- 마감재의 가격, 두께, 열전도율, 열성능 데이터는 제조사 자료, 시험성적서, 표준 자료 또는 추정값을 사용한다.
- 외기 온도, 실내 설정 온도, 냉난방 효율, 전력 단가는 시스템에 사전 설정된 기준값을 사용한다.
- 연간 에너지 사용량과 에너지 비용은 정밀 해석이 아닌 추정값으로 제공한다.
- 외부 서버, 실시간 API, 별도 센서 및 하드웨어와의 연동은 사용하지 않는다.

# 8. 변경 관리

- 변경 요청은 팀 내 협업 문서 또는 회의 내용을 통해 기록한다. 변경 요청에는 대상 요구사항 ID, 변경 내용, 변경 사유를 작성한다.
- 변경 내용은 팀원 간 협의를 통해 적용 여부를 결정하며, 개발 일정과 구현 난이도에 큰 영향을 주는 변경은 우선순위를 다시 검토한다.
- 승인된 변경사항은 SRS 문서와 관련 기능 구현 내용에 반영하고, 필요한 경우 관련 테스트 케이스도 함께 수정한다.
- 변경 이력에는 변경 날짜, 변경자, 변경 대상, 변경 내용, 변경 사유를 기록한다.
